# My dotfiles
This is where I put my NixOS configuration to make a reproductible configuration.

## Installation
1. Install NixOS
2. Clone the repository
```sh
git clone ssh://git@git.oriondev.fr:2222/orion/dotfiles.git ~/.dotfiles --recursive
```
3. Setup it
```sh
./setup.sh
```
